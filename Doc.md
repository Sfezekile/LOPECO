# [Lopeco Foundation - website]

A static website built with HTML and CSS. This README documents how the project was built and the manual refinements made after the initial AI-assisted build.

---

## Build Process

### 1. Vibe Coding (AI-assisted build)
The first draft of the site was generated through vibe coding:

- **HTML structure**: page layout and sections
- **CSS styling**: visual design and layout
- **Content**: initial copy for each section

### 2. Vectorizing (Figma)
Custom brand assets were vectorized in Figma:

- **Logos**
- **Icons**

### 3. Manual Editing
After the initial build, I refined each section by hand.

#### Hero Section
- Removed eyebrow texts
- Made the header uppercase
- Aligned the logo
- Replaced the placeholder path vector with my own vectorized logo

#### Our Purpose Section
- Removed eyebrow texts
- Removed emojis from the cards

#### Our Story Section
- Set `text-align: justify` on the body text
- Laid out the stat cards in a flex row
- Center-aligned the text inside the stat cards

#### Contact Section
- Removed the contact table list
- Moved the contact details into the footer

#### Footer Section
- Added the logo icon and social media icons
- Added a navigation list
- Added a contact list:
  - Email
  - Phone number
